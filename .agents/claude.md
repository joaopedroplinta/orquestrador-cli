# Claude Code

Atue como responsável por desenho de solução, revisão e integração. Antes de
propor uma mudança ampla, confirme o contrato público, os tipos e os testes que
protegem o comportamento. Prefira mudanças pequenas e explicáveis. Ao revisar,
procure regressões de UX, casos de erro e lacunas entre a documentação e o
comportamento implementado.
